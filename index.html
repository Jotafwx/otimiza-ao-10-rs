⚠️ AVISO IMPORTANTE: Esse código só altera configurações do sistema e do jogo, não contém cheats, mods ou arquivos que possam te banir. Use por sua conta e risco, sempre faça backup antes de aplicar.

🚀 Otimizador para Fivem | PC com 8GB RAM

Salve esse arquivo como otimiza-fivem.bat e execute como Administrador:
bat
@echo off
title Otimizador Fivem - 8GB RAM
cls
echo ==================================================
echo          OTIMIZACAO PARA FIVEM - 8GB RAM
echo ==================================================
echo.
echo Executando ajustes para reduzir uso de memoria e CPU...
echo.

:: ==============================================
:: 1. FECHAR PROCESSOS DESNECESSARIOS
:: ==============================================
echo [1/6] Fechando programas que consomem RAM...
taskkill /f /im spotify.exe >nul 2>&1
taskkill /f /im chrome.exe >nul 2>&1
taskkill /f /im opera.exe >nul 2>&1
taskkill /f /im discord.exe >nul 2>&1
taskkill /f /im teams.exe >nul 2>&1
taskkill /f /im onedrive.exe >nul 2>&1
taskkill /f /im steamwebhelper.exe >nul 2>&1
echo Concluido.
echo.

:: ==============================================
:: 2. AJUSTAR MEMORIA VIRTUAL (ESSENCIAL P/ 8GB)
:: ==============================================
echo [2/6] Ajustando memoria virtual...
wmic pagefileset where name="C:\\pagefile.sys" set InitialSize=12288,MaximumSize=12288
echo Memoria virtual definida para 12GB (ideal para 8GB fisicos).
echo.

:: ==============================================
:: 3. DESATIVAR SERVICOS DESNECESSARIOS
:: ==============================================
echo [3/6] Desativando servicos que consomem recursos...
sc config "SysMain" start= disabled >nul 2>&1
net stop SysMain >nul 2>&1
sc config "DiagTrack" start= disabled >nul 2>&1
net stop DiagTrack >nul 2>&1
sc config "WSearch" start= disabled >nul 2>&1
net stop WSearch >nul 2>&1
echo Concluido.
echo.

:: ==============================================
:: 4. LIMPAR ARQUIVOS TEMPORARIOS
:: ==============================================
echo [4/6] Limpando arquivos temporarios...
del /q/f/s %TEMP%\* >nul 2>&1
del /q/f/s C:\Windows\Temp\* >nul 2>&1
cleanmgr /sagerun:1 >nul 2>&1
echo Concluido.
echo.

:: ==============================================
:: 5. PRIORIZAR PROCESSO DO FIVEM
:: ==============================================
echo [5/6] Configurando prioridade do Fivem...
wmic process where name="FiveM_GTAProcess.exe" CALL setpriority 128 >nul 2>&1
echo Definido como Alta Prioridade.
echo.

:: ==============================================
:: 6. CONFIGURACOES ADICIONAIS NO REGISTRO
:: ==============================================
echo [6/6] Ajustando sistema para usar melhor a RAM...
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" /v LargeSystemCache /t REG_DWORD /d 1 /f >nul 2>&1
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management" /v PagingFiles /t REG_MULTI_SZ /d "C:\pagefile.sys 12288 12288" /f >nul 2>&1
echo Concluido.
echo.

echo ==================================================
echo ✅ OTIMIZACAO FINALIZADA COM SUCESSO!
echo ==================================================
echo Agora abra o Fivem e configure dentro do jogo tambem:
echo - Resolucao: 1280x720 ou 1366x768
echo - Qualidade Texturas: Baixa/Media
echo - Sombras: Baixo ou Desligado
echo - Populacao: 20-30%
echo - Escala de Distancia: 30-40%
echo.
pause
exit

📌 O que esse código faz?

  • Fecha programas que roubam RAM enquanto você joga
  • Ajusta a memória virtual para compensar os 8GB limitados
  • Desativa serviços do Windows que rodam em segundo plano
  • Limpa arquivos temporários que deixam o sistema lento
  • Deixa o processo do Fivem com prioridade alta no processador
  • Ajusta configurações do sistema para usar melhor a memória

💡 DICAS EXTRAS OBRIGATÓRIAS PARA 8GB:

  1. Nunca deixe abertos navegadores, Spotify ou Discord enquanto joga
  2. No Fivem, use o parâmetro de inicialização -heaplimit 4096 para limitar o uso de RAM do jogo
  3. Ative o modo de jogo do Windows
  4. Desative a sincronização vertical (V-Sync) se sentir gargalo no processador
